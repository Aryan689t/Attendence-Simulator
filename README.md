 # 📊 Attendance Simulator

A simple and interactive web application to track subject-wise and overall attendance in real time.

Built using HTML, CSS, and JavaScript, this tool helps students manage their attendance and simulate different scenarios easily.

---

## 🚀 Live Demo

👉  https://aryan689t.github.io/Attendence-Simulator/

---

## ✨ Features

- Add multiple subjects
- Increment / decrement:
  - Classes attended
  - Classes conducted
- Real-time percentage calculation (2 decimal precision)
- Automatic overall attendance calculation
- Delete subjects
- Prevent duplicate subjects
- Data saved using localStorage (persists after refresh)
- Clean dark UI

---

## 🧠 How It Works

For each subject:

Attendance % = (Attended / Conducted) × 100

Overall attendance:

Overall % = (Total Attended / Total Conducted) × 100

All values update instantly when interacting with the app.
